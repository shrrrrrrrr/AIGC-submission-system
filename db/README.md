# 数据库迁移说明

迁移按编号顺序执行。生产执行前必须：

1. 确认目标 PostgreSQL 主版本和独立数据库/账号。
2. 完成逻辑备份并记录备份校验值。
3. 在隔离测试库按顺序执行 `001_auth.up.sql`、`002_mfa_credentials.up.sql`，验证约束、索引和各自回滚脚本。
4. 观察连接数、锁等待和迁移耗时；超出预设窗口立即停止。
5. 迁移失败时先恢复备份或执行经过验证的 down 脚本，不在生产手工改表。

`002_mfa_credentials.up.sql` 为已存在用户表增加 MFA 待确认密文和最近已用 TOTP 计数器；该迁移只增加可空列，回滚时先确认没有依赖这些列的应用版本。当前应用仍使用内存仓储；在 PostgreSQL 仓储完成并通过真实数据库集成测试前，生产启动保护不会解除。
