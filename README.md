# ChinaVR 2026 AI、VR 影像单元投稿系统

本项目用于建设正式赛事投稿、资格审查和评审系统。

当前仓库处于开发启动阶段。设计与交接资料位于 [`docs/`](./docs/)，开发行为以 [`AGENTS.md`](./AGENTS.md) 和 [`docs/08-设计审查与开发交接总清单.md`](./docs/08-设计审查与开发交接总清单.md) 为入口。

## 投稿方式

参赛者将主体作品、制作解析以及按作品形式要求的导览视频发布到认可的公共视频平台，再向本站提交链接。本站只保存经过安全预检的链接和必要元数据，不接收、托管、下载或转码参赛视频。

## 开发状态

- 已完成：设计交接资料阅读、开发基线和 Slice A 验收边界整理。
- 已完成（本地/测试）：账号与会话核心、密码重置、PostgreSQL 事务仓储骨架。
- 已完成（本地/测试）：TOTP 注册接口、AES-256-GCM 密钥密文保存和验证码计数器防重放。
- 已完成（前端原型）：公开首页、登录入口和六步投稿编辑器的响应式界面骨架。
- 已完成（本地/测试）：投稿草稿 API 基础、对象归属、`If-Match` 并发保护、幂等键和链接待检测状态。
- 进行中（生产化）：PostgreSQL 启动接入、生产 MFA 密钥托管、管理员/评审 MFA 初次注册运维流程、Passkey、正式邮件通道。
