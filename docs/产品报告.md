# ChinaVR 2026 AI、VR影像单元投稿系统产品报告

## 一、项目结论

本项目是正式赛事的“赛事主页 + 独立投稿页 + 管理评审端”。参赛者先在赛事主页了解规则，点击“立即投稿”进入独立投稿页；完成账号、资料与链接预检后正式提交。

视频不上传到本站。参赛者需先在公共视频平台发布主体作品和制作解析，并向本站提交链接；VR、交互和实时作品另提交导览视频链接，可补充体验链接。本站在提交前自动检查可可靠核验的要求，任意一条不通过即明确返回不符合的规则并拒绝提交。片头、AI 占比、版权和生成标识等无法可靠自动证明的要求，以强制声明和人工资格审查处理。

## 二、需求与内容基线

- 赛事：ChinaVR 2026 AI、VR影像单元；页面日期、会场和主题均由配置驱动，以官方公告为准。
- 方向：AI、VR与前沿科技；AI、VR与中华优秀传统文化；AI、VR与科学幻想作品。
- 作品：主体作品 2—10 分钟，最低 1920×1080；制作解析不超过 1 分钟；VR/交互/实时作品补充 1—5 分钟导览视频。
- 投稿人：个人或团队；学生填写学校、专业、指导教师。
- 创作披露：核心视听内容原则上不低于 80% AI 生成或深度辅助，填写工具、流程和人工贡献，确认生成合成标识与权利。
- 评分：主题契合度 20、视觉表现力 30、技术创新性 20、叙事/概念深度 30；独立匿名评审提交后锁定。

## 三、自动预检的产品边界

| 要求 | 系统处理 | 提交条件 |
| --- | --- | --- |
| 链接安全、HTTPS、允许平台 | 服务器和隔离 Worker 核验 | 不通过即拒绝 |
| 公开可访问、不需登录 | 通过平台适配器核验 | 不通过即拒绝 |
| 时长与分辨率 | 读取可靠平台元数据后按用途比对 | 不通过或不可核验即拒绝 |
| 主体/解析/导览链接是否齐全 | 根据作品形式核验 | 缺失即拒绝 |
| 官方 3 秒片头 | 强制确认，资格审查人工核验 | 自动预检不能证明 |
| AI 占比、工具和人工贡献 | 强制填写/确认，资格审查人工核验 | 自动预检不能证明 |
| 版权、肖像、音乐、数据和生成标识 | 强制确认，资格审查人工核验 | 自动预检不能证明 |

因此，“提交成功”准确含义是：所有可自动核验的链接规则已通过，所有必填字段与声明已完成；不代表系统已经裁定版权或作品内容合规。

## 四、用户与场景

| 用户 | 主要任务 | 设计回应 |
| --- | --- | --- |
| 参赛者 | 看规则、发布视频、填资料、检测链接、确认投稿 | 赛事主页转化、分步表单、自动保存、逐条失败原因、提交前体检 |
| 赛事管理员 | 审核、退回、打开外部链接、通知、导出 | 状态机、版本快照、受控外链打开、审计 |
| 评审专家 | 查看分配作品、评分、留评语 | 分配制访问、评分草稿、提交锁定、固定维度 |
| 超级管理员 | 配置赛事、账号、备份、追责 | 最小权限、MFA、二次确认、同机隔离 |

## 五、产品结构与视觉方向

1. **赛事主页**：赛事介绍、方向、规则、评审、时间线、通知、资源下载、FAQ；主行动跳转独立投稿页。
2. **参赛者中心**：概览、个人/团队资料、我的投稿、六步编辑器、链接预检状态、提交回执、补充任务、通知。
3. **管理评审端**：仪表盘、投稿列表、资格审查、链接预检结果、受控外部作品链接、评审任务、评分、反馈、导出、用户/配置/审计。

视觉概念采用“光场档案”：纸张、展签、印章和坐标/扫描感结合；公开端偏编辑型展览，投稿端偏安静清晰，后台偏高密度和可扫描。原型用无年份标记与可编辑文本 `CHINAVR 2026` 组合，正式上线前替换为官方 2026 矢量资产。

## 六、关键风险与对策

| 风险 | 对策 |
| --- | --- |
| 链接不公开、失效或平台无法返回元数据 | 预检失败即阻止提交，显示规则；提交前复检；管理员可退回补充 |
| 用户输入 URL 触发 SSRF | 平台白名单、URL 规范化、DNS/IP 双检、隔离出网、禁用/重验重定向、响应上限 |
| 自填声明不真实 | 以声明为提交条件，以资格审查人工核验为最终判断；保留版本和审计 |
| 越权查看链接 | RBAC + 对象归属 + 当前状态校验；管理员/评审打开外链留痕 |
| 同机资源争抢 | 独立进程/容器、端口、数据库、日志、备份和出网身份，不影响其他项目 |
