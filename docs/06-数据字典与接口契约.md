# ChinaVR 2026 AI、VR影像单元投稿系统｜数据字典与接口契约

> 本文是开发实现的字段级合同。正式赛事值尚未确认的字段一律引用 `event_settings` 配置，不在前端或后端代码中写死。待确认项统一见《待核实问题清单》。本站不接收参赛视频文件；所有作品视频均以外部公共平台链接提交。

## 1. 通用约定

- ID 使用 UUID；前端不可依赖数据库自增 ID。
- 时间使用 ISO 8601 UTC 字符串；界面按赛事配置的 `Asia/Shanghai` 显示。
- API 前缀为 `/api/v1`；JSON 键使用 `camelCase`；数据库列可使用 `snake_case`。
- 所有成功响应含 `requestId`；列表响应含 `items`、`nextCursor`。
- `POST` 创建草稿、发起链接预检、正式提交和状态迁移必须携带 `Idempotency-Key`。
- 业务规则拒绝使用 `422`，版本或状态冲突使用 `409`，权限不足使用 `403`；统一错误结构：

```json
{
  "code": "VALIDATION_ERROR",
  "message": "主体作品时长为 11:08，要求为 2—10 分钟。",
  "details": [{ "field": "mediaLinks.mainWork", "reason": "MAIN_DURATION_OUT_OF_RANGE" }],
  "requestId": "req_01..."
}
```

## 3. 数据字典

### 3.1 用户与团队

| 实体.字段 | 类型 | 必填 | 校验/说明 |
| --- | --- | --- | --- |
| `users.id` | UUID | 是 | 主键，不对外按顺序暴露 |
| `users.email` | string | 是 | 小写规范化、唯一、验证后可登录 |
| `users.passwordHash` | string | 是 | 仅服务端；Argon2id 哈希，绝不返回 |
| `users.emailVerifiedAt` | datetime | 否 | 未验证前限制正式提交 |
| `users.displayName` | string | 是 | 2–50 字符，输出转义 |
| `users.mfaEnabled` | boolean | 是 | 管理/评审角色必须为 `true` |
| `profiles.phone` | string | 否 | 按 Q-007 决定是否验证；日志脱敏 |
| `profiles.isStudent` | boolean | 是 | 为 `true` 时学校、专业、导师必填 |
| `profiles.school` / `major` / `advisor` | string | 条件必填 | 学生资料，长度与字符集由 schema 限制 |
| `teams.id` / `teams.name` | UUID / string | 是 | 团队主键；名称 2–100 字符，提交版本中保留快照 |
| `teamMembers.role` | enum | 是 | `contact` 或 `member`；每队恰有一名联系人 |

### 3.2 投稿与版本

| 实体.字段 | 类型 | 必填 | 校验/说明 |
| --- | --- | --- | --- |
| `submissions.id` | UUID | 是 | 投稿逻辑主键 |
| `submissions.receiptNo` | string | 是 | 系统生成、唯一、不可修改，如 `CVR26-XXXXXX` |
| `submissions.ownerUserId` / `teamId` | UUID | 是/否 | 对象级授权依据；个人投稿 `teamId` 为空 |
| `submissions.currentStatus` | enum | 是 | 仅状态机修改 |
| `submissions.currentVersionNo` | integer | 是 | 从 1 开始递增 |
| `submissionVersions.id` / `versionNo` | UUID / integer | 是 | 已提交版本不可变；同一投稿版本号唯一 |
| `submissionVersions.title` | string | 是 | 2–100 字符；去除首尾空白 |
| `submissionVersions.direction` / `workForm` | enum | 是 | 见第 2 节；`other` 时要求说明 |
| `submissionVersions.synopsis` | text | 是 | 50–2,000 字符 |
| `submissionVersions.creativeStatement` | text | 是 | 50–3,000 字符 |
| `submissionVersions.aiContributionPercent` | integer | 是 | 80–100；为参赛者声明，人工资格审查复核 |
| `submissionVersions.aiTools` / `aiWorkflow` / `humanContribution` | array/text | 是 | 工具、流程与人工贡献，不以预检自动判定真伪 |
| `submissionVersions.rightsConfirmed` | boolean | 是 | 必须为 `true` 才可提交 |
| `submissionVersions.aiLabelConfirmed` | boolean | 是 | 必须为 `true` 才可提交 |
| `submissionVersions.templateConfirmed` | boolean | 条件必填 | 官方片头启用时必须为 `true`；资格审查人工核验 |
| `submissionVersions.submittedAt` | datetime | 否 | 仅正式提交后写入 |

### 3.3 外部视频链接与评审

| 实体.字段 | 类型 | 必填 | 校验/说明 |
| --- | --- | --- | --- |
| `mediaLinks.id` | UUID | 是 | 链接逻辑 ID |
| `mediaLinks.versionId` | UUID | 是 | 所属投稿版本；外键保护 |
| `mediaLinks.purpose` | enum | 是 | `mainWork` 和 `makingOf` 必填；`guideVideo` 按形式必填；`experience` 可选 |
| `mediaLinks.originalUrl` | URL | 是 | 仅为安全审计与本人编辑保留；展示时脱敏查询参数 |
| `mediaLinks.canonicalUrl` | URL | 否 | 仅预检通过后生成；不在列表接口泄露 |
| `mediaLinks.provider` / `externalVideoId` | string | 否 | 仅由平台适配器写入，不信任客户端 |
| `mediaLinks.isPubliclyAccessible` | boolean | 否 | 适配器确认无需登录访问 |
| `mediaLinks.durationSeconds` | integer | 否 | 适配器得到；按用途规则校验 |
| `mediaLinks.width` / `height` | integer | 否 | 主体作品需满足配置下限；缺失即 `METADATA_UNAVAILABLE` |
| `mediaLinks.precheckStatus` | enum | 是 | 仅 Worker/服务端更新；非 `passed` 不可提交 |
| `mediaLinks.failureCode` | enum | 否 | 失败时稳定错误码；可有多个失败项的 `precheckFindings` |
| `mediaLinks.precheckFindings` | JSON array | 否 | `{code,field,message}`；不得含第三方原始响应 |
| `mediaLinks.checkedAt` / `expiresAt` | datetime | 否 | 过期时强制重新检测 |
| `reviews.*` / `feedback.message` | 见 PRD | 是/否 | 总分服务端计算；参赛者只可见发布的反馈 |

## 4. 表单校验规则

| 步骤 | 前端即时校验 | 服务端提交校验 |
| --- | --- | --- |
| 1. 基本信息 | 标题、方向、形式、简介长度 | 枚举合法性、`other` 补充字段、归属权限 |
| 2. 主体作品链接 | HTTPS 格式与示例 | 白名单平台、SSRF 安全规则、公开可访问、2—10 分钟、至少 1920×1080、预检为 `passed` |
| 3. 制作解析链接 | HTTPS 格式与示例 | 白名单平台、公开可访问、不超过 1 分钟、预检为 `passed` |
| 4. 导览与体验链接 | VR/MR/实时类型提示 | 这些类型必须有 1—5 分钟且 `passed` 的 `guideVideo`；体验链接按配置可选 |
| 5. 权利与 AI 披露 | 百分比、工具、流程、声明勾选 | 阈值与所有声明为真；此处不是自动版权/片头/AI 真实性证明 |
| 6. 确认提交 | 提交摘要、逐条预检状态 | 重新校验全部步骤、预检未过期、截止时间、当前版本/状态、幂等键 |

前端校验只为体验服务。服务端必须再次执行所有规则；任一必填链接不可核验也必须拒绝提交并返回对应失败码。

## 5. API 契约与样例

### 5.1 身份与个人资料

| 方法与路径 | 权限 | 请求摘要 | 成功结果 |
| --- | --- | --- | --- |
| `POST /auth/register` | 公开 | `email,password,displayName` | `201`，发送验证流程 |
| `POST /auth/login` | 公开 | `email,password,mfaChallenge?` | `200`，建立服务端会话 |
| `POST /auth/logout` | 已登录 | 无 | `204`，撤销当前会话 |
| `POST /auth/password-reset/request` | 公开 | `email` | `202`，通用文案防枚举 |
| `POST /auth/password-reset/confirm` | 一次性令牌 | `token,newPassword` | `204`，撤销全部旧会话 |
| `GET/PATCH /me/profile` | 已登录 | 资料字段 | `200`，当前资料 |

### 5.2 草稿、链接预检与提交

```http
POST /api/v1/submissions
Idempotency-Key: 55bd0ef4-...
Content-Type: application/json

{ "title": "未命名作品", "direction": "frontier_tech", "workForm": "animation" }
```

| 方法与路径 | 权限 | 关键规则 |
| --- | --- | --- |
| `GET /submissions` | 参赛者 | 仅返回本人作品；支持 cursor 和状态筛选 |
| `GET /submissions/:id` | 所有者/管理员 | 草稿可编辑，已提交版本只读 |
| `PATCH /submissions/:id/draft` | 所有者且可编辑 | 采用 `If-Match` 防止多标签覆盖 |
| `POST /submissions/:id/media-links` | 所有者且可编辑 | `purpose,url`；保存后状态为 `pending`，不信任客户端平台/时长 |
| `POST /submissions/:id/media-links/:linkId/prechecks` | 所有者且可编辑 | 创建幂等异步预检；限流；返回 `202` |
| `GET /submissions/:id/media-links/:linkId/precheck` | 所有者/授权管理员 | 只返回安全化状态、元数据及失败规则 |
| `POST /submissions/:id/submit` | 所有者且 `ready` | 事务复核每条必填链接仍 `passed` 且未过期，锁定版本/写审计/通知 |
| `POST /submissions/:id/withdraw` | 所有者，且配置允许 | 仅规定窗口内可撤回；保留历史 |

创建/更新链接样例：

```json
{ "purpose": "mainWork", "url": "https://approved.example/video/abc" }
```

检测失败结果样例：

```json
{
  "precheckStatus": "failed",
  "findings": [
    { "field": "mediaLinks.mainWork", "code": "MAIN_DURATION_OUT_OF_RANGE", "message": "主体作品时长为 11:08，要求为 2—10 分钟。" }
  ],
  "requestId": "req_..."
}
```

### 5.3 管理、评审与受控外链打开

| 方法与路径 | 权限 | 关键规则 |
| --- | --- | --- |
| `GET /admin/submissions` | 管理员/评审 | 评审只能得到被分配作品；列表不返回完整外部 URL |
| `POST /admin/submissions/:id/transitions` | 赛事管理员 | `targetStatus,reason,expectedStatus`；服务端验证状态迁移表 |
| `POST /admin/submissions/:id/reviewer-assignments` | 赛事管理员 | 分配评审，重复分配幂等 |
| `GET/POST/PATCH /admin/submissions/:id/reviews` | 分配评审/管理员 | 评分人只操作自己的评分；总分服务端计算 |
| `POST /admin/submissions/:id/media-links/:linkId/open` | 授权管理员/评审 | 强制 `reason`、写审计、返回此前核验的规范化 URL；不可作通用跳转器 |
| `POST /admin/submissions/:id/feedback` | 赛事管理员 | 发布参赛者可见的反馈；不可泄露内部评语 |
| `POST /admin/exports` | 赛事管理员 | 异步导出，字段白名单、审计、短时取件地址 |
| `GET /admin/audit-logs` | 超级管理员 | cursor 分页、不可修改 |

## 7. 兼容性、测试与变更

- 只新增字段，不破坏旧响应；删除或改义字段需新增 API 主版本。
- 表单草稿允许服务端保存未知字段的迁移前版本，但对外只返回定义字段。
- 必测失败场景：重复提交、并发编辑、预检超时、私网 IP、DNS 重绑定、非允许重定向、伪造平台 URL、需要登录的视频、缺失元数据、越权 ID、重复评分、非法状态迁移、限流与 CSRF。
- 每个接口测试至少覆盖：成功、未登录、无权限、无效输入、并发/幂等、审计记录。
