# ChinaVR 2026 AI、VR影像单元投稿系统｜设计审查与开发交接总清单

> 结论：设计阶段已形成可交接的产品、视觉、技术、数据、接口、测试和运行方案。下一开发 Agent 不需要重做产品设计；应按本清单和 PRD 实现，并在开发结束后执行验收。未定的正式赛事/部署参数按《待核实问题清单》在对应时点集中确认。

## 1. 审查范围与结论

| 审查项 | 结论 | 处理 |
| --- | --- | --- |
| 赛事主页与投稿页 | 一致 | 首页承担赛事介绍与转化；“立即投稿”跳转至独立投稿页，登录后进入参赛者中心 |
| 投稿主路径 | 一致 | 填写公共视频平台链接 → 严格预检 → 版本确认 → 正式提交 → 人工资格审查/评审 |
| 自动核验边界 | 一致 | 自动拦截安全 URL、允许平台、公开可访问、时长、分辨率和完整性；片头、AI 占比、版权、标识由强制声明 + 人工资格审查核验 |
| 链接安全 | 一致 | 平台白名单、隔离 Worker、DNS/IP 双检、禁用/重验重定向、响应上限、外部链接打开审计 |
| 状态机 | 一致 | 以 `draft` 至 `invalid` 的状态表为唯一业务状态来源 |
| 账号身份 | 已统一 | 一期邮箱主登录；手机号为待核实扩展，不阻塞开发 |
| 角色权限 | 一致 | RBAC、对象归属、当前状态三层授权；管理/评审 MFA |
| 数据与 API | 一致 | UUID、服务端校验、幂等键、统一错误结构、cursor 分页 |
| 测试与上线 | 一致 | E2E-01 至 E2E-12、SSRF 测试、恢复演练和隔离验证为上线门槛 |
| 未定赛事/资源参数 | 已集中 | 已核实项不再阻塞；其余按《待核实问题清单》相应时点确认 |

## 4. 开发禁止事项

- 不复制参考站的 ChinaGraph 名称、旧赛事文案或旧视觉素材。
- 不实现参赛视频上传、私有视频托管、视频下载或通用外链跳转器；本站以经预检的公共平台链接作为唯一视频交付物。
- 不用通用 `fetch(url)` 检测用户输入；不绕过平台白名单、出网隔离、DNS/IP 检查或预检失败结果。
- 不允许提交后直接覆盖历史版本，不绕过状态机直接修改作品状态。
- 不把前端校验、隐藏 UI 或自填声明当成自动合规证明。
- 不将正式赛事数值、品牌素材、通知供应商或服务器共享配置自行猜测并写死。
- 不在未完成备份、回滚和隔离验证前连接生产环境。

## 5. 设计阶段完成定义

- 产品范围、非目标、角色、流程、状态与页面职责已定义。
- 赛事主页到独立投稿页的跳转、链接预检组件和失败反馈已定义。
- 数据字段、接口合同、错误处理、权限矩阵和 SSRF 防线已定义。
- 人工资格审查与自动预检的责任边界已定义。
- 测试场景、上线门槛、告警和故障响应已定义。
- 所有非阻塞外部问题已集中登记，不散落在文档正文中。

以上条件均已满足。代码、自动化测试、云资源和最终赛事配置尚未实施或确认，不能据此宣称系统已经开发完成或可上线。
