# 投稿汇总表

入口：管理员工作台 → 投稿汇总表；直达 `#admin?view=table`。

- 使用现有投稿数据库，按编号显示已正式提交的作品；不另建数据副本，不需要导入或迁移。草稿不收录，已撤回等记录仍保留。
- 身份字段使用账号邮箱，不新增姓名、手机号、学校和单位填写项。
- 页面可见时每 10 秒重新读取，隐藏时暂停；恢复可见时刷新。筛选支持编号/作品名/邮箱、方向和状态。每页 50 条，导出不受当前页限制。
- 新增 GET `/api/v1/admin/submissions/table` 与 POST `/api/v1/admin/submissions/table/export`，后者导出真正的 XLSX。保留原列表、CSV 和审查接口。
- 全部接口保留管理员角色、MFA、会话校验；导出另外检查 CSRF 并记录导出审计。链接复制/打开复用既有受控接口。
- Excel 包含当前表单的全部用户填写字段、声明、四类链接与核验状态、编号/时间/版本/状态，时间为北京时间。长文字完整保留，输入按文本而非公式处理。
- 分享方式为下载文件后发送，或手动导入飞书；未连接飞书、未创建匿名分享链接。导出文件是快照。

## 验证

`npm test` 包含汇总表测试；也可单独运行 `npm run test:table`。

覆盖：53 条历史投稿跨页、草稿排除、撤回记录、新投稿出现、中文筛选、普通用户/MFA/CSRF 拒绝、权限撤销、XLSX 回读与长文本/公式文本、全量及筛选导出、审计。

浏览器实测：管理员登录、10 秒自动刷新、筛选下载并回读 Excel、复制链接、切回审查、390px 视口、首页/投稿/人员页面访问。后端 PostgreSQL 测试使用现有模拟测试，尚未在真实 PostgreSQL 数据库中验证本功能。
