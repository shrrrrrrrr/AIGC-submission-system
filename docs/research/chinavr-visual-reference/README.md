# ChinaVR 历届视觉素材与 2026 UI 参考

更新日期：2026-09-22

## 使用边界

- 本目录中的图片来自历届 ChinaVR 官方网站，仅作为 ChinaVR 2026 投稿系统的视觉研究、内部原型和沟通参考。
- 历届 Logo、会议名称及主视觉可能涉及商标、著作权或会议品牌规范。未经 2026 组委会确认，不应把旧届素材直接作为 2026 正式 Logo，也不应对 Logo 拉伸、重绘、改色或拆分。
- 城市和校园照片具有明确届次语境：昆明、南昌、长春、厦门素材不能用于广州正式页面。
- 正式上线前，应向组委会索取 2026 Logo 的 SVG/AI/PDF 源文件、透明 PNG、深浅底版本、安全留白和最小尺寸规范。

## 视觉沿革

### 稳定元素

- 核心标记长期围绕字母 `VR` 形成，主色为深海军蓝、亮蓝/青色，并以紫红渐变作为局部强调。
- 首页常采用深色科技背景、右侧视觉主体、左侧会议信息和行动按钮的结构。
- 正式学术大会属性通过大面积留白、规整导航、双语栏目标题和主办单位矩阵表达。

### 不稳定元素

- 历届视觉没有形成完全统一的品牌系统：2021/2024 使用线框头显人物，2022 使用紫蓝线条人物，2020 更依赖城市和会场摄影。
- 2024 首页仍复用了早期线框人物素材，说明该图片不应被理解为不可替代的核心品牌资产。
- 历届英文标识、年份排版、字体和 Logo 组合方式变化较大，不能从旧图反推出 2026 官方锁定规范。

## 对现有“光场档案”方案的建议

当前项目的“光场档案”方向可以保留，并把历届视觉作为品牌层，而不是整站照搬：

1. **Logo 层**：原样放置组委会确认的 ChinaVR 标记；年份和“AI、VR 影像单元”作为独立文字，不烘焙进位图。
2. **公开站首屏**：延续历届深蓝底和青色光场，但用作品帧、扫描坐标、光场切片代替通用的“戴头显人物”图库。
3. **正文与规则页**：继续使用项目现有的纸白、暖白、墨黑和朱砂，避免整站变成霓虹科技展页面。
4. **投稿中心**：只在页头、进度线和焦点状态中使用 ChinaVR 蓝青色；表单保持浅色、清晰和低干扰。
5. **管理评审端**：品牌色仅用于导航和选中态，评分、风险和状态仍遵循现有语义色，不让品牌色覆盖安全反馈。
6. **广州语境**：若需要城市元素，应重新取得广州或正式会场授权图片；不要复用厦门大学、昆明湿地或长春城市图。

## 建议的临时品牌变量

以下颜色是基于历届视觉的近似工作值，仅供原型，不是官方色值：

```css
:root {
  --chinavr-navy: #123b72;
  --chinavr-blue: #278fbd;
  --chinavr-cyan: #68d2d0;
  --chinavr-magenta: #b5145b;
  --chinavr-ink: #071a34;
}
```

建议只将 `navy → blue → magenta` 渐变用于 Logo 邻近区域、首屏光场和少量强调，不用于正文背景或高频按钮。项目现有朱砂主行动色可继续保留，使投稿操作与会议品牌装饰形成清楚分工。

## 2026 正式素材待办

- ChinaVR 2026 主 Logo 与横版/竖版组合。
- 深色底、浅色底和单色版本。
- 三个主办学会 Logo 的正式矢量文件与排列顺序。
- “AI、VR 影像单元”的正式中文名、英文名和是否允许自建子品牌。
- 广州会场、主视觉、摄影图和作品静帧的使用授权。
- Logo 安全区、最小显示尺寸、禁用方式及页脚版权文字。
- 官方片头 PSD/AE 工程与网站是否必须保持一致。
