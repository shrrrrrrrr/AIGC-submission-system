# ChinaVR 2026 AI、VR影像单元投稿系统｜待核实问题清单

> **使用规则**：本表只记录仍未获得正式答案、但不阻塞当前代码开发的问题。开发阶段以“已核实”区的结论为准；部署或对外发布前，再按本表规定的节点集中确认其余事项。

## 一、已核实，可直接进入开发

| 编号 | 已确认结论 | 开发处理 |
| --- | --- | --- |
| Q-002 | 投稿截止时间采用 `2026-10-12 23:59:59`，北京时间 | 截止时间仍做成后台赛事配置；测试环境使用同结构的模拟日期 |
| Q-003 | 主体作品和不超过 1 分钟的制作解析均先上传至公开视频平台，赛事网站提交两条持续可访问的链接。VR、交互和实时作品另提交 1—5 分钟录屏或导览视频链接，可附体验链接 | 本站不托管主体视频；投稿编辑器分别收集主体作品、制作解析、导览和体验链接。主体/解析/条件必填导览链接必须通过安全 URL、允许平台、公开可访问、时长、分辨率（主体）预检，否则显示具体失败规则并禁止提交；作品归属、片头、AI/版权等由声明和人工资格审查处理 |
| Q-005 | 评审专家使用独立账号；评审彼此匿名；评分提交后锁定，仅超级管理员可因留痕原因解锁 | 按既有 RBAC、评分锁定和审计方案实现 |
| Q-007 | 一期采用邮箱验证登录，不新增短信 MFA；手机号不是登录必填项 | 以邮箱作为唯一登录标识；手机号保留为可选个人资料字段。后续若改为手机号登录，需要新增开发，不是纯配置 |
| Q-009 | 采用站内通知加邮件通知；短信仅在未来有明确需求时再接入 | 实现站内通知和可替换邮件通道；不实现短信验证码和短信通知 |
